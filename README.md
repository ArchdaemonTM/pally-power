### Quick Start (IONOS Shared Hosting)

1. Create subdomain `pally-profile.goldhatconsulting.com` in IONOS panel
2. Create a MariaDB database in IONOS panel (note the host, user, pass)
3. Upload ALL files via FTP/SFTP to the subdomain document root
4. Navigate to `https://pally-profile.goldhatconsulting.com/install/`
5. Enter your database credentials and click **Install**
6. **DELETE the `/install/` directory** after successful installation

### Security

- **No user accounts** — edit tokens ARE the auth mechanism
- Edit tokens: 64 hex chars (256-bit), compared with `hash_equals()`
- All inputs sanitized: `strip_tags()` + `mb_substr()` length limits
- Prepared statements everywhere (no SQL injection surface)
- Rate limiting on suggestions (10/hour/IP, DB-backed)
- CORS restricted to configured origins
- Install directory must be deleted after setup
- Config.php contains credentials — ensure it's not web-accessible

### Post-Installation

1. Delete `/install/` directory
2. Test: visit the site, take the Heart Song Quiz, create a character
3. Verify API: visit `/api/?action=gamedata` in browser
4. Add content: INSERT new callings, specializations, etc. directly in the DB
5. Review suggestions: check `suggestions` table, change status to 'approved'
